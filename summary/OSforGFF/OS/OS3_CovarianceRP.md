## Overview

Proves **reflection positivity of the free covariance**, $\mathrm{Re}\,\langle \Theta f, C f\rangle \ge 0$,
for test functions $f$ supported at positive time ($x_0 \le 0 \Rightarrow f(x) = 0$), using the mixed
representation derived in `OS3_MixedRep`:
$$\langle \Theta f, C f\rangle = \frac{1}{2(2\pi)^{d-1}}\int_{\bar k}\frac{1}{\omega}\,\Bigl\lvert\int \tilde f(t,\bar k)\,e^{-\omega t}\,dt\Bigr\rvert^2\,d\bar k \ \ge\ 0.$$

The key factorization: for positive-time support $\lvert x_0+y_0\rvert = x_0+y_0$, so
$e^{-\omega\lvert x_0+y_0\rvert} = e^{-\omega x_0}\,e^{-\omega y_0}$ and the bilinear form collapses to a
perfect square $\int (1/\omega)\lvert F_\omega(\bar k)\rvert^2\,d\bar k$ with
$F_\omega(\bar k) = \int \tilde f(t,\bar k)\,e^{-\omega t}\,dt$ the weighted Laplace–Fourier transform.

The file is **dimension-generic**: it works over section variables `{d : ℕ} [Fact (2 ≤ d)]` (with
`{m : ℝ} [Fact (0 < m)]` and `[GFFPropagator d m]` supplied per declaration). It uses the generic complexified bilinear form
